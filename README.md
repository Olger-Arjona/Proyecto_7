# Análisis de Anuncios de Vehículos Usados

## Descripción del proyecto

Esta aplicación web interactiva permite explorar de forma visual un conjunto de datos de anuncios de venta de vehículos usados (`vehicles_us.csv`). Fue desarrollada con **Streamlit** como parte de un proyecto de análisis exploratorio de datos (EDA).

## Funcionalidad

La aplicación permite:

- Visualizar una vista previa de los datos del conjunto de anuncios de vehículos.
- Generar un **histograma** que muestra la distribución del kilometraje (`odometer`) de los vehículos.
- Generar un **gráfico de dispersión** que muestra la relación entre el kilometraje y el precio de venta de los vehículos.
